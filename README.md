# 以撒小测试 · 找隐藏房

《以撒的结合》隐藏房测验。楼层按游戏真实的生成规则算出，你在游戏自己的小地图上用炸弹（忏悔+ 还有红钥匙）找出隐藏房、超级隐藏房和究极隐藏房，和大家比积分。

**在线使用：<https://lceoliu.github.io/find-Isaac-hiding-rooms/>**

## 玩法

- **今日挑战**：按日期出的 7 层，所有人同一套题，每天北京时间 0 点换题。
- **随机挑战**：随机种子的 7 层。
- **自由练习**：自己输入种子和参数，可以打开"显示概率""提示下一步"和完整地图，不计分。

挑战里没有提示，完整地图要等这一层找完或放弃之后才能看。一层结束后可以点"看 AI 怎么找"：在地图上一步步回放 AI 的选择、它当时看到的概率和结果；结果卡上会给出 AI 平均要用几颗炸弹、几次红钥匙。

计分：隐藏房 +100，超级隐藏房 +150，究极隐藏房 +200；炸弹或红钥匙什么都没找到 −25；一次不空、全部找到再 +50。每层不低于 0 分。

## 说明

- 支持胎衣†（Afterbirth+ v1.06）和忏悔+（Repentance+）。胎衣† 的楼层生成和游戏逐层核对过；忏悔+ 的生成器是静态移植，还没和游戏核对。
- 概率和 AI 只用你看得见的信息推算：地图形状、房间布局和门位、这一层有哪几种隐藏房、你炸过或开过的格子。不会读取隐藏房的真实位置。
- 点房间可以看它的布局，用原版贴图画（胎衣† 借用忏悔+ 的美术）。地板花纹、石头样式这类随机细节可能和游戏里不同。
- 全部在浏览器里运行：生成器是 Python，用 [Pyodide](https://pyodide.org/)（从 jsDelivr 加载）执行。第一次打开要下载几 MB。
- 排行榜存在 [Supabase](https://supabase.com/)，只保存玩家名、浏览器里随机生成的玩家 id 和每层的分数。分数在浏览器里计算，排行榜仅供娱乐。

## 文件

| 路径 | 内容 |
|---|---|
| `index.html`、`style.css`、`js/` | 页面 |
| `config.js` | 运行方式和排行榜地址（Supabase 的 publishable key，本来就是公开的） |
| `py/macro.zip` | 楼层生成器和推算代码（Python） |
| `data/*.zip` | 生成器读取的游戏数据：房间布局、实体表、小地图图片等 |
| `art/` | 房间布局用的背景图和预渲染的贴图；`art/ui/` 是首页的菜单素材、以撒的动画、图标和音效 |

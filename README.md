# 找隐藏房

《以撒的结合》找隐藏房练习。输入种子，页面按游戏的生成规则算出这一局的真实楼层，你在游戏自己的小地图上用炸弹（忏悔+ 还有红钥匙）找出隐藏房、超级隐藏房和究极隐藏房。

**在线使用：<https://lceoliu.github.io/find-Isaac-hiding-rooms/>**

- 支持胎衣†（Afterbirth+ v1.06）和忏悔+（Repentance+）。胎衣† 的楼层生成和游戏逐层核对过；忏悔+ 的生成器是静态移植，还没和游戏核对。
- "显示概率"和"提示下一步"默认关闭。它们只按生成规则推算，用的是你看得见的信息：地图形状、房间布局和门位、你炸过的格子。不会读取隐藏房的真实位置。
- 点房间可以看它的布局，用原版贴图画（胎衣† 借用忏悔+ 的美术）。地板花纹、石头样式这类随机细节可能和游戏里不同。
- 全部在浏览器里运行：生成器是 Python，用 [Pyodide](https://pyodide.org/)（从 jsDelivr 加载）执行，不需要服务器。第一次打开要下载几 MB。

## 文件

| 路径 | 内容 |
|---|---|
| `index.html`、`style.css`、`js/`、`config.js` | 页面 |
| `py/macro.zip` | 楼层生成器和推算代码（Python） |
| `data/*.zip` | 生成器读取的游戏数据：房间布局、实体表、小地图图片等 |
| `art/` | 房间布局用的背景图和预渲染的贴图 |
